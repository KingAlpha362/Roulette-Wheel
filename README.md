# Roulette Pocket Colour Exercise

A conditional-logic exercise that assigns a colour to a numbered roulette pocket.

## ✨ Highlights

- Reads a pocket number from 0 to 36.
- Uses ranges and parity checks to select a colour.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "Roulette.py"
```

Follow the prompts in the terminal.

## 🗂️ Repository guide

- [Roulette.py](Roulette.py)

## 📝 Project notes

The current red/black branches do not match a standard roulette wheel. Out-of-range input can leave `color` undefined. Treat this as a practice exercise.
